# Flexbox and Grid Layout

## About This Project

This project is part of my software and web development course. I'm using it to practise CSS Flexbox and Grid and learn how to organise content into clean, well-structured layouts.

I want to understand when to use each layout method and how they can help make websites look good across different screen sizes.

## What I'm Working On

- **Flexbox** – arranging elements in rows and columns and controlling the space between them.
- **CSS Grid** – creating layouts using rows and columns.
- **Alignment** – positioning content using properties such as `justify-content` and `align-items`.
- **Spacing** – controlling gaps, padding and margins between elements.
- **Responsive layouts** – adjusting the layout for different screen sizes.
- **Flexbox vs Grid** – understanding when each method is most useful.
- **Combining layouts** – using Flexbox and Grid together where it makes sense.

## Technologies Used

- HTML5
- CSS3

## What I've Learned

This project gives me a chance to practise different ways of arranging content with CSS. I'm learning how Flexbox and Grid work, how their properties affect a layout and how to make pages more responsive without relying on fixed positioning.

I'll continue building on the project as I learn more layout techniques.

## How to View the Project

1. Download or clone this repository.
2. Open `index.html` in your browser.
